Input Penghasilan

Penghasilan pegawai per masa pajak. Gaji dan tunjangan mengikuti data di menu Data Pegawai; klik Input pada tiap baris untuk mengisi lembur, honor, dan penghasilan lain lewat jendela pop-up. PPh 21 dihitung otomatis dengan metode TER.

Kolom di tabel hanya menampilkan data. Untuk mengubah penghasilan, klik tombol Input pada baris pegawai. Lembur & Lain-lain otomatis dijumlahkan ke tunjangan. Pegawai nonaktif terkunci pada masa setelah berhenti — kelola status di menu Data Pegawai.
